# 自己的实验

[课程路线](../course/STUDY_GUIDE.md) · [当前记录](../course/TRACKER.md) · [分支操作](../docs/setup/README.md#用学习分支保持-main-为空白模板)

`main` 保持空白课程模板。ML/DL/LLM 分别在 `codex/study-ml`、`codex/study-dl`、`codex/study-llm` 学习分支记录成果。开始时再创建目录，不提前生成空项目。

| 成果 | 路径 | 对应服务器配置 |
|---|---|---|
| 通用课程实验 | `work/courses/ml/`、`dl/`、`llm/` | `ml`、`dl`、`llm` |
| 按已有示例编号练习 | `work/bootcamp/week1/`～`week3/` | `week1`～`week3` 或对应课程配置 |
| 中文补充题 | `work/assignments/A01/`～`A08/` | `core-a01`～`core-a08` 或对应课程配置 |
| NJU 模板实现 | `work/nju-llm-2026/a0/`～`a5/` | `nju-a0`～`nju-a5` 或对应课程配置 |

同一个任务只保留一份主要实验，写清运行方式、数据来源、结果与局限。成果链接记入学习分支的当前记录。模型、环境和输出由 Git 忽略；将少量重要指标写进任务说明。
