# 我的练习与项目

[返回项目首页](../README.md) · [学习指南](../course/STUDY_GUIDE.md) · [进度表](../course/TRACKER.md)

这里保存自己编写或从学校原件复制后修改的代码、笔记和项目成果。按任务建立子目录，例如 `intro-classification/`、`intro-network/`、`p1_tabular/`；开始对应任务时再创建，不提前生成空目录。

每个任务至少保存代码或 Notebook，以及说明如何运行、数据来源和结果的 README。完成后把成果链接填入进度表。

`course/projects/` 保存题目要求，`library/` 保存学校原件。已有 Week 1 学习笔记在 [入门课程目录](../course/bootcamp/week1/README.md)，继续保留在那里。
