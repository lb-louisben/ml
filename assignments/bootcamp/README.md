这里细化整体指南的阶段 0。`week1/2/3` 是内容编号，按顺序推进，可以跨自然周完成。每次默认 **90～120 分钟**；以下是安排估计，实际耗时以自己的记录为准。

## 先判断从哪里开始

- 首次使用项目：按 [环境说明](../../docs/setup/README.md) 运行 [环境测试](../../docs/setup/00_环境测试.ipynb)。准备环境的时间单独记录。
- Python / NumPy 不熟：从 W1-01 开始。
- 已学过前两天：先独立完成 W1-01/02 的练习，能解释结果就跳到 W1-03；目前没有完成证据，因此不自动替你勾选。
- 分类和小网络都在回归项目验收后依次开展。

## 学习地图与跳转

| 部分 | 次数与建议用时 | 本段具体内容 | 最终成果 |
|---|---|---|---|
| [Week 1：数据与回归](week1/README.md) | 10 次，15～20 小时 | Python → NumPy → 读表 → 清洗 → EDA → 划分 → 回归 → Pipeline → 评价 → 整理 | 自己的学生成绩回归项目 |
| [Week 2：分类与评估](week2/README.md) | 7 次，10.5～14 小时 | 正类/划分 → 混淆矩阵 → 逻辑回归 → 树 → 阈值 → 冻结评价 → 复现 | 一个分类项目 |
| [Week 3：小网络](week3/README.md) | 10 次，15～20 小时 | shape → 链式求导 → 前向 → 损失 → 反传 → 梯度检查 → 小样本训练 → 框架对照 → 正式实验 → 整理 | NumPy MLP 与 PyTorch 对照 |

合计约 40.5～54 小时，另留环境配置、卡点补练和 T0 诊断时间；数学和编程基础较弱时允许延长。每周 5 次约需 6 周，每周 3 次约需 9 周；这只是排期参考，不是截止日期。

## 第一次实现：材料与代码在同一份教程里

| 跟着做什么 | 教程 | 对应单元 |
|---|---|---|
| 一次完整的分类实验 | [分类带练 Notebook](week2/classification_walkthrough.ipynb) | W2-01～07 |
| 手算到 NumPy 反向传播 | [NumPy 网络带练 Notebook](week3/01_numpy_network_walkthrough.ipynb) | W3-01～07 |
| 自动微分对照与完整训练 | [PyTorch 带练 Notebook](week3/02_pytorch_training_walkthrough.ipynb) | W3-08～10 |

每份教程按“必要概念 → 小例子 → 中文注释代码 → 预期性质与检查 → 独立变式”展开。第一次直接在原位置顺序执行：源码 Notebook 保持材料与示例，自己的变式写入 `work/`。Notebook 内的材料链接供进一步阅读，不要求先跳出去读完整门课。

不要一次 Run All 就算学完：先猜一段输出，再运行并解释，随后改一个参数或输入验证理解。最后的独立练习不看示例重写，填写成果证据后才算完成该单元。自动验证只检查演示代码，不替你完成练习。

NumPy 网络的 [实现文件](week3/numpy_mlp.py) 与两本 Week 3 教程同目录。框架环境见 [PyTorch 设置](../../docs/setup/DEEP_LEARNING.md)，运行检查见 [教材验证记录](VALIDATION.md)。

## 每次 90 分钟怎样分配

| 时间 | 做什么 |
|---|---|
| 0～10 分钟 | 不看答案复述上次内容，读本次完成标准 |
| 10～30 分钟 | 只读本次指定章节，先猜例子输出 |
| 30～75 分钟 | 独立写代码、手算或整理实验；保存失败尝试 |
| 75～90 分钟 | 核对结果，写一条错因，更新进度 |
| 可用的额外 30 分钟 | 补未完成的核心练习，或做一次小变式 |

一次只有 45～60 分钟时，把一个单元分为“阅读/手算”和“实现/验收”两次；有 2～3 小时时先补核心练习，再做可选扩展，不自动增加下一门课。

## 完成、卡住和复盘

每个单元都写明 **打开哪里 → 独立练习 → 完成标准 → 保存什么**。材料中的完整 A 系列作业、广度和 Bonus 不自动成为本次任务。

连续卡住约 20 分钟：保存最小失败例子，记录预期、实际结果和报错；回到单元指向的先修内容，或请人解释这个具体卡点。能运行后还要自己重写一次，不能仅凭参考答案运行成功过关。

每三次学习，用下次开头 10 分钟复做一道之前的题。到阶段末再整理项目，所有中间练习都进入同一个成果，不额外交重复作业。

所有状态只记在 [进度表](../../course/TRACKER.md)，本页和周目录只给任务说明。项目评分见各周验收；完成第三部分后做 [T0 数学诊断](../../course/tests/T0_math_diagnostic.md)，用错题安排数学基础阶段。
