# 作业与可运行练习

本目录集中保存题目、入门 Notebook、作业模板、公开测试和运行需要的小数据。服务器可只检出某一部分；讲义、参考书和课程资料位于 `course/`、`library/` 或 GitHub Releases。

| 内容 | 入口 | 个人成果位置 |
|---|---|---|
| Python、数据分析、分类与小网络 | [Bootcamp](bootcamp/README.md) | 已有笔记继续保留原 Notebook；独立实现放 `work/bootcamp/` |

| NJU A0～A5 | [NJU 作业](nju-llm-2026/README.md) | `work/nju-llm-2026/a0/`～`a5/` |
| 海外课程指定作业包 | [按文件下载方法](../docs/SERVER_GUIDE.md#overseas) | 在 `work/` 下解压所选作业包 |

个人目录在开始对应任务时创建。模板保留原始题目和 TODO，自己的实现和报告放在 `work/`；当前 NJU A0 实现已保存至 `work/nju-llm-2026/a0/`。
