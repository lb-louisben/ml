# A02：真实数据审计

来源类型：本仓库自制；结构参考 Berkeley Data 100 的 data lifecycle、cleaning 与 EDA。只选与当前单元有关的题，不要求整份完成。

选择一个至少 1,000 行、8 个字段的公开数据集。不要先建复杂模型；这份作业的对象是数据本身。

## 任务

1. 数据卡（15）：来源、许可、采集对象、时间范围、每行含义、目标字段、潜在受影响人群。
2. schema 审计（20）：dtype、单位、合法范围、唯一性、主键候选、缺失编码、重复记录。
3. 清洗函数（20）：原始数据只读；clean(raw) 返回新对象；二次清洗结果应一致。
4. 划分与泄漏（15）：定义预测时点，列出至少 3 个可能泄漏的字段或过程。
5. EDA（20）：至少 4 张有问题驱动的图；每张图写观察、证据、替代解释。
6. 风险备忘录（10）：选择偏差、测量误差、缺失机制、公平或隐私至少各讨论一项中的三项。

## 必做检查

- 每条清洗规则都报告影响行数，不允许静默删除。
- 同时报告缺失数量和比例。
- 分类变量的 rare levels 单独检查。
- 若标签在不同群体或时间上分布不同，必须展示。
- 图表标题、坐标、单位和样本量齐全。

## 可保留的成果

data_card.md、audit.ipynb、src/clean.py、reports/data_quality.csv、README.md。原始大数据不要直接提交 Git；在 README 给出获取与校验方式。
