# Tests

测试必须限时、闭卷、独立完成。允许一张自己制作的 A4 公式纸；不得搜索、运行代码或使用 AI。完成后再打开 [答案与评分要点](SOLUTIONS.md)，用不同颜色订正。

| 测试 | 时长 | 阶段 | 通过线 |
|---|---:|---|---:|
| [T0 数学与基础诊断](T0_math_diagnostic.md) | 75 min | 入门后诊断 / 阶段 1 出口 | 70 |
| [T1 本科 ML 期中](T1_undergraduate_midterm.md) | 120 min | 阶段 2 | 70 |
| [T2 研究生 ML 期末](T2_graduate_ml_final.md) | 150 min | 阶段 3 | 70 |
| [T3 DL/LLM 口试](T3_dl_llm_oral.md) | 45～60 min | 阶段 5 | 70 |

T0 首次用于诊断，不设通过门槛；表中的 70 分适用于数学阶段出口。入门不要求完成 T3。

重测时不要原样背答案：先让学习伙伴或 AI 依据错误类型生成不同数字/场景的等价题，再在无帮助条件下完成。
