# T1：本科机器学习期中

120 分钟，100 分。强调应用、评价与解释。

## A. 数据与实验设计（20 分）

1. 医院数据中同一患者有多次就诊记录。随机按行划分有什么风险？设计更合理的 split。（6）
2. 预测贷款申请时是否违约。字段包含“最终催收次数”。判断能否使用并说明预测时点。（5）
3. 缺失值可能是 MCAR、MAR 或 MNAR。各用一句话区分，并说明为什么 MNAR 特别困难。（6）
4. 为什么先看完整数据的相关图再划测试集也可能造成信息泄漏？（3）

## B. 回归（20 分）

5. 写出 Ridge 的目标函数。alpha 增大时 bias 与 variance 通常如何变化？（6）
6. 两模型的 MAE 相同，但 A 的 RMSE 更高。可以推断 A 的残差有什么特点？（4）
7. R²=-0.3 如何解释？（4）
8. 一个类别变量有 5 类。使用 one-hot + 线性回归时如何处理截距与共线性？Pipeline 中 fit 编码器应使用哪些数据？（6）

## C. 分类与指标（30 分）

9. 混淆矩阵：TP=40, FP=10, FN=20, TN=130。计算 precision、recall、accuracy、F1。（10）
10. 欺诈检测应优先 ROC-AUC 还是 PR-AUC？说明类别分布与业务代价如何影响选择。（6）
11. 调低二分类阈值，precision 和 recall 一般如何变化？为什么不是数学保证？（5）
12. 模型 A AUC 更高，模型 B 在部署阈值上的成本更低。应选哪个？还需要什么证据？（5）
13. 解释 calibration 与 discrimination 的差别。（4）

## D. 模型与泛化（30 分）

14. 决策树 max_depth 从 2 增到 50，训练/验证误差通常如何变化？画示意图。（6）
15. bagging 与 boosting 的核心差别是什么？随机森林额外引入了什么随机性？（8）
16. k-fold CV 的 k 增大带来哪些计算与统计权衡？时间序列为何不能普通 shuffle CV？（6）
17. RBF SVM 中 C 与 gamma 都很大时可能出现什么边界？（4）
18. PCA 只在训练集 fit 后，为什么可以 transform 验证/测试集？若每个 split 各自 fit 会怎样？（6）
