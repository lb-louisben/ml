## W2-01｜定义正类、划分与 baseline

**首次带做：** [Notebook · 定义正类、划分与 baseline](classification_walkthrough.ipynb#w2-01)。跟着完成标签映射、两次分层划分、索引检查、训练集审计和 Dummy；本节示例先分出 20% 测试，再从余下数据分出 25% 验证。

**材料：** [数据与实验设计](../../materials/04_data_and_experiment_design.md) 的划分和泄漏部分；数据集自身的说明。

**独立练习：**

1. 写出一行代表什么、输入字段、原标签与新标签对应关系、两种错误的含义。
2. 用两次分层划分得到约 60%/20%/20% 的 train/validation/test，固定 `random_state=42`；分别保存索引、人数和正类比例。
3. 检查索引互斥且覆盖原数据；只在训练集检查缺失、重复与数值范围。如发现跨集合重复，先查原因并修正协议再建模。
4. 在训练集拟合多数类 DummyClassifier，记录验证 accuracy；暂不打开测试预测结果。

**完成标准：** 能准确指出 FP、FN 各表示什么，解释为什么分层划分仍不能自动解决实体重复或时间泄漏。保存数据卡、标签映射和 split 检查。

<a id="w2-02"></a>

## W2-02｜从混淆矩阵理解指标

**首次带做：** [Notebook · 从四个计数写出指标](classification_walkthrough.ipynb#w2-02)。先手算四格，再用带零分母标记的指标函数核对；运行候选模型前记录代价与完整平局规则。

**材料：** [分类与指标 §1～2](../../materials/06_classification_and_metrics.md)。

**独立练习：**

1. 给定 `TN=50, FP=10, FN=5, TP=35`，手算 accuracy、precision、recall、F1，再写代码核对。
2. 为 W2-01 的 Dummy 补上混淆矩阵与这些指标；遇到没有正预测时明确零分母处理规则，避免把未定义指标当作性能证据。
3. 自造一组 100 个标签，其中只有 5 个正类，分析全部预测负类会发生什么。
4. 写出假设代价 `cost = 5 × FN + FP`，作为后续模型与阈值选择的主标准；平局先比较 FN，再按事先写定的简单模型偏好排序；带做示例约定线性模型优先，同族内 C 较小或树较浅优先。跨家族的偏好是教学约定，不是通用复杂度结论。

**完成标准：** 不查公式能从四个计数推指标，并解释高 accuracy 为什么可能掩盖漏报。保存手算和核对结果；ROC/PR 曲线完整推导暂不要求。

<a id="w2-03"></a>

## W2-03｜逻辑回归输出的是概率

**首次带做：** [Notebook · 训练逻辑回归并保存概率](classification_walkthrough.ipynb#w2-03)。从 sigmoid 小例子进入 Pipeline，比较三组 C，检查 classes_ 和 scaler 的训练数据来源。

**材料：** [线性模型 §3](../../materials/05_linear_models.md)，回看 Week 1 Pipeline。

**独立练习：**

1. 写出 score → sigmoid → probability → threshold → label 的流程。
2. 用 StandardScaler + LogisticRegression 构造 Pipeline，全部拟合只使用训练集；确认没有未处理的收敛警告。
3. 固定其他设置，比较 `C=0.1、1、10`；暂用阈值 0.5，在训练/验证集记录 accuracy、recall、F1 和 cost。
4. 检查 `classes_` 与 `predict_proba` 列顺序；取 5 个验证样本展示正类概率与预测标签。

**完成标准：** 解释 C 与正则化强弱的关系；能证明 scaler 只见过训练数据；分清概率和硬标签。保存每个配置及验证预测概率，W2-05 会复用。

<a id="w2-04"></a>

## W2-04｜决策树与过拟合

**首次带做：** [Notebook · 比较决策树与训练差距](classification_walkthrough.ipynb#w2-04)。实现三种深度、统一比较表和趋势图，保存带原样本索引的验证概率供下一节复用。

**材料：** [树与集成](../../materials/07_trees_and_ensembles.md) 的决策树部分。

**独立练习：**

1. 固定随机种子，分别训练 `max_depth=2、4、8` 的决策树，其余配置固定。
2. 用同一数据划分和阈值 0.5 记录训练/验证指标、叶节点数及 cost；保存验证概率。
3. 与逻辑回归、Dummy 放进同一张比较表；画一张深度与 train/validation 表现关系图。
4. 写出“训练表现变好是否伴随验证改善”的观察；没有观察到明显过拟合也照实说明，不为得到预设结论改数据。

**完成标准：** 解释树为何通常不需要标准化、深度为何改变复杂度，且不把特征重要性解释为因果效应。随机森林与 boosting 本阶段不增加。

<a id="w2-05"></a>

## W2-05｜在验证集选择模型与阈值

**首次带做：** [Notebook · 只用验证集选择并冻结](classification_walkthrough.ipynb#w2-05)。用缓存概率比较 54 个预定组合；选中后立即保存模型配置、阈值和训练中位数切片规则。

**材料：** [分类与指标 §4](../../materials/06_classification_and_metrics.md)。

**独立练习：**

1. 先在纸上预测：把阈值从 0.5 改为 0.3，哪些样本会改变预测？哪些不变？
2. 对已经保存的 6 个训练配置，统一尝试阈值 `0.1～0.9`、步长 0.1；不新增配置。
3. 每行记录 model、配置、threshold、TN/FP/FN/TP、precision、recall、F1、cost；按 W2-02 的规则选定模型和阈值，进一步平局时选最接近 0.5 的阈值，仍平局时选较小阈值；完整规则在查看候选分数前写定。
4. 用最终选中模型比较阈值 0.5 与选中阈值，解释代价变化来自哪些错误变化。

**完成标准：** 所有选择仅使用验证集；能解释验证分数受反复选择影响，最终表现仍需留出的测试集检查。保存选择规则、结果表和选中配置。

## W2-06｜冻结、最终评价与错误分析

**首次带做：** [Notebook · 一次最终评价与错误切片](classification_walkthrough.ipynb#w2-06)。读取冻结记录后才产生测试预测，复用同一份结果完成混淆矩阵、预定切片和具体错误分析。

**材料：** [分类与指标 §6](../../materials/06_classification_and_metrics.md)；前面自己的数据卡与结果表。

**独立练习：**

1. 在看测试结果前写下冻结记录：特征、预处理、模型参数、阈值、主指标；直接使用已在训练集拟合的模型，不临时重拟合后沿用旧阈值。
2. 预先定义两个互补切片：`mean radius` 低于训练集中位数，以及大于等于该中位数；固定切点，解释这是教学分析切片。
3. 对冻结模型和 Dummy 做最终测试评价，报告混淆矩阵、指标和 cost；对选中模型按上述两组报告样本量和错误率。
4. 展示三个具体错误样本，说明真实标签、概率、预测及可能原因。若错误不足三个则全部展示，如实注明数量。

**完成标准：** 不用测试结果重新选阈值或特征；小切片只作为线索，不作因果结论。保存 `metrics.json`、错误案例和结果解释。

## W2-07｜复现与 10 分钟自我讲解

**首次带做：** [Notebook · 保存、恢复与自己讲解](classification_walkthrough.ipynb#w2-07)。保存模型、配置、环境和结果，恢复模型并核对验证预测一致；再按检查清单独立讲解自己的项目。

**材料：** 本项目全部记录，不新增阅读。

**独立练习：** 重启内核运行 Notebook，核对冻结结果；写 README，说明数据、标签映射、运行方法、选择规则、主要发现与局限。复现相同冻结方案可以重跑，不重新调参。

**过关检查：**

- 手算一个新混淆矩阵，解释 FP/FN；
- 画出训练、验证选择、冻结、测试的完整流程；
- 指出三种泄漏，说明各自修复方法；
- 解释为什么选这个模型和阈值，而非只说“分数更高”；
- 从干净内核复现所有记录。
