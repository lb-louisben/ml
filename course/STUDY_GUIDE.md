# ML → 深度学习 → LLM：三门课课程设计

[项目首页](../README.md) · [进度](TRACKER.md)

这是面向本科生与研究生的课程设计，也是本项目唯一的学习路线。目标是建立模型全貌，掌握训练和评估，能够读懂完整工程代码，再逐步实现核心模块与独立项目。以下是自主设计的课程，不代表 Stanford 的正式教学大纲。

## 1. 先建立模型地图

机器学习是总领域。深度学习是机器学习中的一类方法，通常使用多层神经网络。**DNN 是深度神经网络的统称，不是与 CNN 并列的一个唯一模型；MLP、CNN、RNN 与 Transformer 都可以构成深度神经网络。** LLM 则是语言建模的模型与系统类别，现代主流实现广泛使用 Transformer。

| 模型家族 | 代表模型 | 要解决什么问题 | 在哪里学习 |
|---|---|---|---|
| 线性模型 | Linear Regression、Ridge、Lasso、Logistic Regression | 回归、分类、可解释基线 | M2–M3 |
| 近邻与概率模型 | kNN、Naive Bayes、LDA/QDA | 相似度分类、条件概率建模 | M4 |
| 树与集成 | Decision Tree、Random Forest、Gradient Boosting | 非线性表格预测、模型组合 | M5–M6 |
| 间隔与核方法 | Linear SVM、Kernel SVM | 分类边界与非线性特征映射 | M7 |
| 无监督学习 | k-means、PCA、GMM/EM；DBSCAN 选学 | 聚类、压缩、结构发现 | M8–M9 |
| 全连接神经网络 | Perceptron、MLP | 学习非线性表示，理解训练机制 | D1–D2 |
| 卷积网络 | LeNet、AlexNet、VGG、ResNet；EfficientNet 选学 | 利用图像的局部结构与共享参数 | D4–D5 |
| 循环与序列网络 | RNN、LSTM、GRU、Seq2Seq | 处理有顺序的数据与长期依赖 | D6 |
| 注意力架构 | Attention、Transformer；ViT 选学 | 内容相关的信息交互与表示学习 | D7–D8 |
| 深度生成模型 | Autoencoder、VAE、GAN、Diffusion | 表示压缩、分布建模、生成 | D9–D10 |
| 语言模型 | n-gram、神经语言模型、BERT 类、GPT 类、T5 类 | 建模、理解与生成文本 | L1–L4 |

先认识每个家族的用途、输入输出和基本想法，再逐个实现。模型年代、参数量或名字不能代替实验比较；同一个问题先有简单基线。

## 2. 先修知识与课程顺序

已有数学基础的学生用小例子查漏补缺，不安排额外一整门数学课。以下知识在首次使用前补齐：

- Python 函数、类、文件读写；NumPy 数组、索引与广播。
- 矩阵乘法、向量与张量 shape；均值、方差、条件概率。
- 导数、偏导数、链式法则的含义；梯度下降如何更新参数。
- 数据、标签、模型、参数、损失函数分别是什么。

推荐采用 **知识依赖串行、已具备先修条件的模块并行**。

| 阶段 | 主课 | 可并行内容 | 下一阶段入口条件 |
|---|---|---|---|
| A | M1–M4：实验流程、线性/逻辑回归、基础分类 | 所需 Python/数学补练 | 能独立划分数据、训练基线、解释 loss 与验证指标 |
| B | D1–D3：MLP、Autograd、训练诊断 | M5–M9：树、集成、SVM、聚类与降维 | 能读懂一个训练循环，说明每个张量的 shape，排查过拟合 |
| C | D4–D8：CNN → RNN → Attention → Transformer | M10–M12：泛化与 ML 项目；仅有余力时并行 | 能实现小网络，解释因果 mask、残差与归一化 |
| D | L1–L8：语言建模、训练、适配与评价 | D9–D12：生成模型、自监督和 DL 项目，按方向选择 | 能跑通小语言模型，区分模型损失、生成质量与应用表现 |
| E | 每门课的研究生扩展；选一个综合项目 | 按项目问题补理论和系统知识 | 有基线、一个改进假设、消融与可复现证据 |

精力有限时，按 **ML → DL → LLM** 完整串行也成立。并行时每次仍只有一个正在实现的项目，不同时提交三份大作业。

每门课定义 12 个教学单元。一个单元可拆为概念课、代码实验和独立练习；它不等于必须在一个自然周内完成。课堂开课可按学期安排，自学按掌握情况推进。

## 3. 第一门课：机器学习 ML

**本科目标：** 面对表格数据，能选择合理模型、建立可靠实验、解释模型差异，并交付训练与预测流程。

**研究生目标：** 从目标函数、概率假设、优化和泛化角度解释结果，设计有证据的比较实验。

| 单元 | 本科核心内容 | 代码与实验 | 研究生扩展 |
|---|---|---|---|
| M1 模型与实验 | 回归/分类/聚类；训练/验证/测试；泄漏与基线 | 同一个数据集跑 Dummy 与简单模型 | 实验估计偏差、分布变化、指标不确定性 |
| M2 线性回归 | 最小二乘、梯度下降、Ridge/Lasso、标准化 | sklearn Pipeline；手写小型梯度下降 | 闭式解、条件数、正则化与 MAP 的联系 |
| M3 逻辑回归 | sigmoid、交叉熵、多分类、阈值 | 二分类、混淆矩阵、PR/F1；改阈值 | 凸性、校准与代价敏感决策 |
| M4 基础分类模型 | kNN、Naive Bayes、LDA/QDA 的假设与差别 | 同一划分比较边界和误判 | 生成式与判别式建模、MLE/MAP |
| M5 决策树 | 分裂准则、深度、剪枝、非线性特征 | 树深度变化与训练/验证曲线 | 偏差、方差与不稳定性 |
| M6 集成学习 | Bagging、Random Forest、Gradient Boosting；了解 XGBoost | 对比线性、树、森林、boosting | 函数空间视角、加法模型与相关性 |
| M7 SVM 与核 | 最大间隔、支持向量、核的用途 | 线性核/RBF 核；C 与 gamma 的影响 | 原问题/对偶、KKT、核的条件 |
| M8 聚类 | k-means、距离、初始化；DBSCAN 作为对照 | 小数据可视化，解释聚类结果 | 目标函数、局部最优、聚类评价局限 |
| M9 降维与概率聚类 | PCA、GMM、EM 的基本流程 | PCA 重构与二维投影；k-means/GMM 对比 | SVD、潜变量、EM 推导 |
| M10 模型选择与泛化 | 交叉验证、学习曲线、特征选择、误差分析 | 固定协议比较模型，分析数据量影响 | 泛化界、贝叶斯观点与不确定性估计 |
| M11 工程流程 | 数据契约、保存/加载模型、批量预测、复现 | 一条命令训练，另一条命令预测 | 分布漂移、校准、监控与复现实验 |
| M12 课程项目 | 完整表格预测项目与模型比较 | 可复现结果表、错误案例、简短说明 | 一个明确假设、消融、多 seed 或区间估计 |

**项目规模：** 一个小型公开数据集，主要比较线性模型与树/集成模型。其他算法用小型练习了解机制，不把所有模型都塞进项目，也不要求全套竞赛调参。

现有入门代码：[回归项目](../assignments/bootcamp/week1/project/08_Student_performance_project.ipynb)、[分类带练](../assignments/bootcamp/week2/classification_walkthrough.ipynb)。已有 Python/NumPy 基础时直接进入它们，日级补充 Notebook 按需查阅。

## 4. 第二门课：深度学习 DL

**先修：** M1–M3 的训练、损失和评估；矩阵 shape 与链式法则。无需先完成全部经典 ML。

**本科目标：** 能读懂并修改 PyTorch 工程，训练、保存和调用小模型，解释 MLP/CNN/RNN/Transformer 的设计。

**研究生目标：** 诊断优化与泛化问题，理解不同表示和生成模型，设计复现与架构比较。

| 单元 | 本科核心内容 | 代码与实验 | 研究生扩展 |
|---|---|---|---|
| D1 Tensor 与 Autograd | batch、shape、计算图、梯度、Dataset/DataLoader | 一个可从头执行的 PyTorch 训练循环 | 梯度检查、数值精度与计算开销 |
| D2 MLP / DNN | 全连接层、激活、损失、前向和反传 | 两层 MLP；NumPy 与 Autograd 对照 | 初始化、Jacobian 与梯度传播 |
| D3 稳定训练 | SGD/Adam、学习率、正则化、Dropout、归一化 | 过拟合小 batch；定位不收敛/过拟合 | AdamW、调度、梯度裁剪与优化分析 |
| D4 CNN 基础 | 卷积、padding、stride、pooling、感受野；LeNet/AlexNet/VGG | 小型图像分类网络，逐层记录 shape | 参数共享、感受野与归纳偏置 |
| D5 现代视觉网络 | ResNet、迁移学习与微调 | 同数据比较 MLP/CNN；迁移学习另做小实验 | BatchNorm、深度可分离卷积；ViT 选学 |
| D6 序列模型 | Embedding、RNN、LSTM、GRU、Seq2Seq | 一个短序列任务，比较循环状态 | 梯度消失、teacher forcing、序列误差 |
| D7 Attention | Q/K/V、缩放点积、多头、padding/causal mask | 从小矩阵实现 attention，验证 mask | 复杂度、数值稳定性与长序列限制 |
| D8 Transformer | 残差、LayerNorm、FFN、位置表示；encoder/decoder | 组装一个小 block，解释每个模块 | Pre/Post Norm、RoPE 与架构消融 |
| D9 表示与生成 | Autoencoder 的重构；VAE/GAN 的基本目标 | 核心路线只做小型 AE；VAE/GAN 按方向选一个 | ELBO、重参数化、对抗训练稳定性 |
| D10 Diffusion | 噪声预测与去噪采样的基本想法 | 选学二维/小图像演示，避免大规模训练 | score、采样器与条件生成 |
| D11 迁移与自监督 | 预训练表示、迁移、对比学习概念 | 用已有表示做小型下游任务 | 对比目标、数据增强、CLIP 类方法 |
| D12 课程项目 | 图像或序列任务，基线→训练→推理→错误分析 | 完整代码、一个改动、曲线和预测示例 | 一次小范围论文/方法复现及消融 |

D1–D8 是共同主线。D9–D11 在本科课中讲清概念，深度实现按视觉、生成或语言方向选择；研究生选一个专题深入，不要求同时训练所有生成模型。

现有起点：[PyTorch 训练带练](../assignments/bootcamp/week3/02_pytorch_training_walkthrough.ipynb)。[NumPy 手写网络](../assignments/bootcamp/week3/01_numpy_network_walkthrough.ipynb) 用于解释反传和验证实现；不作为开始 PyTorch 前的一整段额外课程。

## 5. 第三门课：大语言模型 LLM

**先修：** PyTorch 训练循环、交叉熵、Embedding、Attention 和 Transformer。可以提前使用现成模型做体验，但模型训练单元依赖这些基础。

**本科目标：** 理解语言模型如何训练和生成，能使用可公开取得的小模型，完成一个有评价的文本功能。

**研究生目标：** 理解预训练、适配、对齐与推理系统的取舍，能够设计可复现研究实验。

| 单元 | 本科核心内容 | 代码与实验 | 研究生扩展 |
|---|---|---|---|
| L1 语言建模 | token、条件概率、下一 token；n-gram 到神经模型 | 比较简单基线与小模型；理解 perplexity | 数据分布、长尾与评价局限 |
| L2 Tokenizer 与数据 | 字符/子词、BPE、特殊 token、序列切块 | 小文本实现/检查 tokenizer；输入/标签错位 | Unicode、训练集污染、去重与打包 |
| L3 模型家族 | BERT 类 encoder、GPT 类 decoder、T5 类 encoder-decoder | 同一输入观察掩码与输出的不同 | 预训练目标、参数化与位置表示 |
| L4 小型语言模型 | causal Transformer、LM head、loss、训练循环 | 小语料从训练到生成；复用 D7–D8 的模块 | 权重绑定、初始化与资源估算 |
| L5 生成与推理 | greedy、temperature、top-k/top-p、停止条件 | 改解码参数，记录质量与重复现象 | KV cache、吞吐/延迟/显存与量化 |
| L6 使用预训练模型 | 模型/分词器一致性、prompt、结构化输出 | 先读一份完整推理程序，再改输入和输出约束 | batching、版本管理与评价协议 |
| L7 适配与微调 | SFT、LoRA、冻结参数、数据格式 | 小样本适配，比较微调前后的具体任务 | 优化与遗忘；全参/PEFT 取舍 |
| L8 评价与可靠性 | 测试集、任务指标、人工检查、幻觉与数据泄漏 | 固定一小套案例，做错误分析 | 鲁棒性、污染、评测统计与局限 |
| L9 检索与 RAG | 文档切块、检索、重排、引用与回答 | 选做有来源的问答功能，分别评价检索/回答 | 混合检索、grounding 与消融 |
| L10 偏好与对齐 | 偏好数据、奖励、RLHF/DPO 的位置与基本目标 | 读懂小型偏好实验；研究生再实现 | 目标推导、数据偏差与奖励投机 |
| L11 规模与训练系统 | 计算/数据/参数规模；混合精度、并行训练概念 | 小模型资源统计，不要求多 GPU | scaling laws、分布式、profiling 与通信 |
| L12 课程项目 | 分类、抽取、问答或小型生成，选择一个功能 | 基线、适配/提示、评价、可运行推理接口 | 一个训练或系统改进假设、消融与资源报告 |

L1–L8 是共同主线；L9–L11 根据应用或研究方向选学。Agent 只在明确项目需要时扩展。项目允许小模型与小数据，完整课堂概念不等于必须进行昂贵的大规模预训练。

现有配套：[NJU 作业目录](../assignments/nju-llm-2026/README.md)。A0–A4 按张量运算、归一化、MLP、Attention 与 Transformer 分别选片段，不再要求开始 LLM 前把六份作业全部刷完。选择任务后再在 [个人实验目录](../work/README.md) 建立自己的实现；旧个人副本已清理。

## 6. 每个模型怎样教，完整代码怎样用

每个核心单元统一采用以下顺序：

1. **问题与直觉：** 这个模型要解决什么问题，相比已学模型改变了什么。
2. **最小例子：** 画输入输出，写 shape，手算一个很小的例子。
3. **完整参考程序：** 先执行并解释数据加载、模型、loss、优化、评估与保存各段的作用。
4. **局部改写：** 替换一个模块/目标/参数，先预测变化，再验证。
5. **独立实现：** 关闭参考程序，只重建当前最关键模块，不重复抄整套工程。
6. **诊断与迁移：** 给出一次失败实验或换一个小数据集，解释现象和局限。

课程作业只分三种：代码阅读与解释、核心模块实现、小项目。每门课只保留一个贯穿项目；同一个结果可以同时支撑算法比较、错误分析和报告，不另交一份重复作业。

| 层次 | 达到什么才算掌握 |
|---|---|
| 本科核心 | 会选择模型，理解输入输出，能运行和修改完整代码，能解释关键模块与结果 |
| 研究生扩展 | 能写出关键目标/假设，提出可检验的改进，做消融与严谨比较，说明实现和证据的边界 |

每门课评价：概念与代码解释 20%，核心实现 30%，贯穿项目 40%，复现与反思 10%。分数用于课堂评估，自学时对应掌握证据；不把额外题库和历年考试当作必做清单。

## 8. 你现在从哪里开始

先读第 1 节模型地图，然后进入 **M1 → M2 → M3**：用一个小数据集完成训练、验证与预测，再进入 **D1 → D2 → D3**。数学和 NumPy 卡在哪里就补哪里。已有基础足够时，不必先刷完所有 Python、数学与清洗 Notebook。

第一份具体成果：解释一个现成回归/分类程序的每一段，自己改一个条件，保存结果和解释。当前可使用现有回归项目或分类带练；完成状态由实际成果决定，不根据示例运行记录自动替你勾选。
