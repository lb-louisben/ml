## 每章的完成标准

以下用于当前选定的学习主题；仅预习或查阅时，不新增完整作业。

1. 不看正文，用自己的话写出 5 句摘要。
2. 手算章节里的 worked example。
3. 完成“自测”，口头解释每个答案。
4. 按学习指南选一套同主题练习；学校练习与 A 系列默认二选一，已有成果满足要求时补缺项即可。不能用“看懂了”替代实现。
5. 在 [TRACKER](../TRACKER.md) 的简短复盘中记录成果链接、一个卡点和下一步。
