## 每章的完成标准

1. 不看正文，用自己的话写出 5 句摘要。
2. 手算章节里的 worked example。
3. 完成“自测”，口头解释每个答案。
4. 做对应 assignment；不能用“看懂了”替代实现。
5. 把错误写进 TRACKER 的每周复盘。
