# Assignments

这里是按主题查找的练习库，不是要从 A01 刷到 A08 的第二份计划。选用范围以 [学习指南](../STUDY_GUIDE.md) 为准；与学校同主题练习默认二选一。

每份作业都同时包含概念、实现和解释。默认独立完成；提交目录中应有 README、代码/Notebook、结果文件和 assistance 声明。统一评分见 [ASSESSMENT.md](../ASSESSMENT.md)。

| 编号 | 建议阶段 | 预计时间 | 作业 |
|---|---|---:|---|
| A01 | 数学桥梁 | 8～10 h | [线性代数、概率与优化](A01_math_and_optimization.md) |
| A02 | 数据科学 | 5～7 h | [真实数据审计](A02_data_audit.md) |
| A03 | 经典 ML | 8～10 h | [从零实现回归](A03_regression_from_scratch.md) |
| A04 | 经典 ML | 8～12 h | [分类、阈值与错误切片](A04_classification_evaluation.md) |
| A05 | 研究生 ML | 10～14 h | [概率模型与核方法](A05_probabilistic_and_kernel_ml.md) |
| A06 | 深度学习 | 10～14 h | [反向传播与训练诊断](A06_backprop_and_training.md) |
| A07 | Transformer | 10～14 h | [从零实现 self-attention](A07_transformer_from_scratch.md) |
| A08 | LLM 系统 | 8～12 h | [RAG 的检索与答案评价](A08_rag_evaluation.md) |

本目录是中文补充练习。官方作业原件及 starter code 已归档至 [本地资料库](../../library/README.md)。按 [学习指南](../STUDY_GUIDE.md) 选择作业，在自己的工作目录完成。
